#### Шаг 1. Переключитесь на пользователя root

Откройте терминал и выполните команду перехода в режим суперпользователя:

```bash
su -
```

Система попросит ввести пароль администратора (root), который вы задавали при установке Debian. 

#### Шаг 2. Установите пакет sudo

В некоторых минимальных сборках Debian утилита sudo не установлена по умолчанию. Установите её командой:

```bash
apt update && apt install sudo -y
```

#### Шаг 3. Добавьте пользователя в группу sudo

Замените имя_пользователя на логин вашего обычного аккаунта в системе: 

```bash
usermod -aG sudo bebeto
```

#### Шаг 4. Перезагрузите компьютер

Чтобы изменения вступили в силу, группам пользователя необходимо обновиться. Для этого закройте терминал, выйдите из системы (Log Out) и зайдите снова (либо полностью перезагрузите ПК). 

#### Шаг 5. Проверка

Откройте терминал под своим обычным пользователем и проверьте работу sudo, выполнив любую административную команду (система попросит ввести ваш личный пароль): 

```bash
sudo apt update
```
