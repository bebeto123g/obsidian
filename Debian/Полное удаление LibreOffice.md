# Полное удаление остатков LibreOffice в Debian 13

Инструкция по очистке операционной системы от неиспользуемых зависимостей, языковых пакетов и конфигурационных файлов, оставшихся после удаления LibreOffice.

## Шаг 1. Удаление всех связанных пакетов по маске

При стандартном удалении в системе часто остаются компоненты и языковые пакеты. Эта команда находит и полностью удаляет все пакеты, содержащие в названии `libreoffice`, включая их конфигурационные файлы.

```bash
sudo apt purge "libreoffice*"
```

## Шаг 2. Очистка неиспользуемых зависимостей

После удаления основных пакетов в системе остаются библиотеки, которые устанавливались вместе с LibreOffice, но больше не требуются другим программам.

```bash
sudo apt autoremove --purge
```

## Шаг 3. Удаление пользовательского профиля и кэша

*Опционально.* Полноценная очистка настроек текущего пользователя (история файлов, шаблоны, конфигурация интерфейса).

```bash
rm -rf ~/.config/libreoffice
```

## Шаг 4. Проверка результатов

Чтобы убедиться, что в системе не осталось компонентов офисного пакета, выполните проверку списка установленных пакетов:

```bash
dpkg -l | grep libreoffice
```

> [!info] Результат
> Если команда ничего не вернула, значит LibreOffice удален полностью.
