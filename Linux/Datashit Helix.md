
# Helix: краткая инструкция

Helix — модальный текстовый редактор для терминала, ориентированный на работу с LSP, мультикурсорным редактированием и встроенной навигацией по проекту.

Запуск:

```bash
hx
```

Открыть файл:

```bash
hx src/main.rs
```

Открыть проект или текущую директорию:

```bash
hx .
```

---

## 1. Основная концепция

Helix работает в нескольких режимах:

| Режим   | Назначение                               |
| ------- | ---------------------------------------- |
| Normal  | Навигация, выделение, операции с текстом |
| Insert  | Ввод текста                              |
| Select  | Работа с выделением                      |
| Command | Выполнение команд через `:`              |

После запуска редактор находится в **Normal mode**.

Основные переходы:

- `i` — перейти в режим вставки перед курсором
- `a` — перейти в режим вставки после курсора
- `o` — создать строку ниже и перейти в режим вставки
- `O` — создать строку выше и перейти в режим вставки
- `Esc` — вернуться в Normal mode
- `v` — перейти в Select mode
- `:` — открыть командную строку

В Helix сначала создаётся выделение, а затем над ним выполняется операция. Например:

1. Нажать `w`, чтобы выделить следующее слово.
2. Нажать `d`, чтобы удалить его.

# 2. Навигация

## Перемещение по тексту

| Клавиша | Действие |
|---|---|
| `h` | Влево |
| `j` | Вниз |
| `k` | Вверх |
| `l` | Вправо |
| `w` | К началу следующего слова |
| `e` | В конец слова |
| `b` | К началу предыдущего слова |
| `W` | К началу следующего WORD |
| `B` | К началу предыдущего WORD |
| `0` | В начало строки |
| `^` | К первому непробельному символу |
| `$` | В конец строки |
| `gg` | В начало файла |
| `ge` | В конец файла |
| `Ctrl-d` | На полстраницы вниз |
| `Ctrl-u` | На полстраницы вверх |
| `Ctrl-f` | На страницу вниз |
| `Ctrl-b` | На страницу вверх |

`w`, `e` и `b` работают не только как навигационные команды, но и как команды выделения.

Например:

- `w` — выделить следующее слово;
- `2w` — выделить два слова;
- `b` — выделить предыдущее слово;
- `gg` — перейти в начало файла;
- `G` — перейти в конец файла.

## Переход к строке

Нажмите:

```text
:
```

и выполните:

```text
goto 42
```

Это переместит курсор на строку 42.

Также можно использовать:

```text
goto line 42
```

# 3. Выделение

| Клавиша | Действие |
|---|---|
| `x` | Выделить текущую строку |
| `X` | Расширить выделение на соседние строки |
| `v` | Перейти в Select mode |
| `w` | Выделить следующее слово |
| `e` | Выделить до конца слова |
| `b` | Выделить предыдущее слово |
| `f<char>` | Найти символ в строке |
| `t<char>` | Перейти перед символом |
| `%` | Перейти к парной скобке |
| `s` | Выбрать символы по поиску |

Примеры:

```text
x
```

Выделяет текущую строку.

```text
2x
```

Выделяет две строки.

```text
v
```

Позволяет расширять выделение клавишами навигации.

# 4. Изменение текста

| Клавиша | Действие |
|---|---|
| `d` | Удалить выделение |
| `c` | Удалить выделение и перейти в Insert mode |
| `y` | Скопировать выделение |
| `p` | Вставить после курсора |
| `P` | Вставить перед курсором |
| `r` | Заменить выделение одним символом |
| `~` | Изменить регистр |
| `u` | Отменить действие |
| `U` | Повторить отменённое действие |
| `>` | Увеличить отступ |
| `<` | Уменьшить отступ |
| `J` | Объединить строки |
| `Alt-j` | Переместить строку или выделение вниз |
| `Alt-k` | Переместить строку или выделение вверх |

Примеры:

```text
x d
```

Удалить текущую строку.

```text
w c
```

Заменить следующее слово.

```text
x y
```

Скопировать текущую строку.

```text
x p
```

Вставить скопированную строку ниже.

```text
x >
```

Увеличить отступ текущей строки.

# 5. Поиск и замена

## Поиск

| Клавиша | Действие |
|---|---|
| `/` | Поиск вперёд |
| `?` | Поиск назад |
| `n` | Следующее совпадение |
| `N` | Предыдущее совпадение |
| `*` | Поиск слова под курсором |
| `Alt-n` | Следующее совпадение в выделении |
| `Alt-p` | Предыдущее совпадение в выделении |

Пример:

1. Нажмите `/`.
2. Введите:

```text
TODO
```

3. Нажмите `Enter`.
4. Используйте `n` и `N` для перехода между совпадениями.
5. Нажмите `Esc`, чтобы закрыть строку поиска.

## Замена

Откройте командную строку через `:` и используйте:

```text
%replace old new
```

Например:

```text
%replace foo bar
```

Для замены с регулярным выражением:

```text
%replace /foo_[0-9]+/bar/
```

Перед массовой заменой желательно сначала выполнить поиск и проверить совпадения.

# 6. Работа с файлами и буферами

## Основные команды

Команды вызываются через `:`.

| Команда            | Действие                             |
| ------------------ | ------------------------------------ |
| `:open file.txt`   | Открыть файл                         |
| `:write`           | Сохранить файл                       |
| `:write!`          | Принудительно сохранить              |
| `:quit`            | Закрыть текущий буфер                |
| `:quit!`           | Закрыть без сохранения               |
| `:write-quit`      | Сохранить и выйти                    |
| `:buffer-close`    | Закрыть буфер                        |
| `:new`             | Создать новый буфер                  |
| `:vsplit file.txt` | Открыть файл в вертикальном сплите   |
| `:hsplit file.txt` | Открыть файл в горизонтальном сплите |
| `:reload`          | Перезагрузить файл                   |
| `:cd path`         | Изменить текущую директорию          |
| `:pwd`             | Показать текущую директорию          |

Часто используемые сочетания:

| Сочетание | Действие |
|---|---|
| `Space f` | Открыть файловый picker |
| `Space F` | Открыть файловый picker в текущей директории |
| `Space b` | Выбрать открытый буфер |
| `Space w` | Сохранить файл |
| `Space q` | Закрыть текущий буфер |
| `Space Q` | Закрыть все буферы |
| `Space ?` | Открыть меню команд |

В разных версиях Helix отдельные сочетания могут изменяться. Комбинация `Space ?` позволяет посмотреть доступные действия в текущем режиме.

# 8. Работа с проектом

## Открытие проекта

Перейдите в корневую директорию проекта:

```bash
cd ~/projects/my-app
hx .
```

Или запустите Helix напрямую:

```bash
hx ~/projects/my-app
```

Корень проекта обычно определяется по таким файлам и директориям:

- `.git`
- `package.json`
- `Cargo.toml`
- `go.mod`
- `pyproject.toml`
- `CMakeLists.txt`
- `Makefile`

Для корректной работы LSP желательно запускать Helix из корня проекта.

## Файловый поиск

Нажмите:

```text
Space f
```

Начните вводить имя файла. Навигация по результатам:

| Клавиша | Действие |
|---|---|
| `Ctrl-j` | Следующий файл |
| `Ctrl-k` | Предыдущий файл |
| `Enter` | Открыть выбранный файл |
| `Esc` | Закрыть picker |

## Поиск по проекту

Нажмите:

```text
Space /
```

Введите искомую строку. Helix использует внешний инструмент поиска, обычно `ripgrep`.

Пример установки `ripgrep`:

```bash
# Debian/Ubuntu
sudo apt install ripgrep

# Fedora
sudo dnf install ripgrep

## Навигация по символам

| Сочетание | Действие |
|---|---|
| `Space s` | Символы текущего файла |
| `Space S` | Символы всего рабочего пространства |
| `Space d` | Диагностики текущего файла |
| `Space D` | Диагностики проекта |
| `Space a` | Доступные code actions |
| `Space r` | Переименовать символ |
| `Space k` | Показать документацию под курсором |
| `Space h` | Найти ссылки на символ |

LSP-переходы:

| Сочетание | Действие |
|---|---|
| `g d` | Перейти к определению |
| `g D` | Перейти к объявлению |
| `g r` | Найти ссылки |
| `g i` | Перейти к реализации |
| `g t` | Перейти к определению типа |

# 9. Установка языковых серверов

Helix не устанавливает LSP-серверы автоматически. Их нужно установить отдельно.

## Rust

```bash
rustup component add rust-analyzer
```

## Python

Варианты серверов:

```bash
pip install python-lsp-server
```

или:

```bash
pip install pyright
```

## TypeScript и JavaScript

```bash
npm install -g typescript typescript-language-server
```

## Go

```bash
go install golang.org/x/tools/gopls@latest
```

## C и C++

Для `clangd`:

```bash
# Debian/Ubuntu
sudo apt install clangd

# Fedora
sudo dnf install clang-tools-extra
```

## Bash

```bash
npm install -g bash-language-server
```

## JSON, YAML и HTML

Некоторые серверы устанавливаются через Node.js:

```bash
npm install -g vscode-langservers-extracted
```

Этот пакет включает серверы для HTML, CSS, JSON и ESLint.

# 10. Конфигурация LSP

Конфигурация Helix обычно находится в:

```text
~/.config/helix/
```

Основные файлы:

```text
~/.config/helix/config.toml
~/.config/helix/languages.toml
```

Создание директории:

```bash
mkdir -p ~/.config/helix
```

Проверить расположение конфигурации можно командой:

```bash
hx --health
```

Также полезно проверить доступные языковые серверы:

```bash
hx --health rust
```

---

## Пример `languages.toml`

Пример настройки Rust:

```toml
[[language]]
name = "rust"
language-servers = ["rust-analyzer"]
auto-format = true

[language-server.rust-analyzer.config.check]
command = "clippy"

[language-server.rust-analyzer.config]
cargo = { allFeatures = true }
checkOnSave = { command = "clippy" }
```

Пример настройки Python с `pyright`:

```toml
[[language]]
name = "python"
language-servers = ["pyright"]
auto-format = true

[language-server.pyright]
command = "pyright-langserver"
args = ["--stdio"]
```

Пример настройки TypeScript:

```toml
[[language]]
name = "typescript"
language-servers = ["typescript-language-server"]
auto-format = true

[language-server.typescript-language-server]
command = "typescript-language-server"
args = ["--stdio"]
```

Пример настройки Go:

```toml
[[language]]
name = "go"
language-servers = ["gopls"]
auto-format = true

[language-server.gopls]
command = "gopls"
args = ["serve"]
```

Пример настройки C/C++:

```toml
[[language]]
name = "cpp"
language-servers = ["clangd"]
auto-format = true

[language-server.clangd]
command = "clangd"
args = ["--background-index"]
```

# 11. Проверка работы LSP

Откройте файл нужного языка:

```bash
hx main.rs
```

Проверьте:

1. Отображаются ли ошибки и предупреждения.
2. Работает ли переход к определению через `g d`.
3. Показывается ли документация через `Space k`.
4. Работает ли переименование через `Space r`.
5. Форматируется ли файл через `:format`.

Основные команды LSP:

| Команда | Действие |
|---|---|
| `:lsp-restart` | Перезапустить LSP |
| `:lsp-stop` | Остановить LSP |
| `:lsp-workspace-command` | Выполнить команду рабочего пространства |
| `:format` | Форматировать текущий файл |
| `:reload` | Перезагрузить файл |

Если LSP не запускается, проверьте наличие исполняемого файла:

```bash
which rust-analyzer
which pyright-langserver
which typescript-language-server
which gopls
which clangd
```

Также запустите:

```bash
hx --health
```

# 12. Форматирование кода

Для форматирования текущего файла:

```text
:format
```

Чтобы форматирование выполнялось автоматически при сохранении, добавьте в `languages.toml`:

```toml
[[language]]
name = "rust"
auto-format = true
```

Для Rust форматирование выполняется через `rustfmt`:

```bash
rustup component add rustfmt
```

Для Go установите стандартные инструменты Go. Обычно `gopls` использует `gofmt` автоматически.

# 13. Настройка `config.toml`

Пример базовой настройки:

```toml
theme = "tokyonight"

[editor]
line-number = "relative"
mouse = true
cursorline = true
true-color = true
bufferline = "multiple"
color-modes = true
auto-save = true

[editor.indent-guides]
render = true
character = "│"

[editor.l end-of-line-diagnostics]
render = "hint"

[editor.inline-diagnostics]
cursor-line = "warning"

[keys.normal]
C-s = ":write"
C-q = ":quit"
```

В последнем блоке опечатка недопустима: правильная настройка должна выглядеть так:

```toml
[editor.end-of-line-diagnostics]
render = "hint"
```

Полный минимальный вариант:

```toml
theme = "tokyonight"

[editor]
line-number = "relative"
mouse = true
cursorline = true
true-color = true
bufferline = "multiple"
color-modes = true
auto-save = true

[editor.indent-guides]
render = true
character = "│"

[editor.end-of-line-diagnostics]
render = "hint"

[editor.inline-diagnostics]
cursor-line = "warning"

[keys.normal]
C-s = ":write"
C-q = ":quit"
```

# 14. Полезные повседневные сценарии

## Открыть проект и найти файл

```bash
cd ~/projects/my-app
hx .
```

В Helix:

```text
Space f
```

Введите имя файла и нажмите `Enter`.

## Найти использование функции

1. Поставьте курсор на имя функции.
2. Нажмите:

```text
g r
```

3. Выберите нужное использование.

## Переименовать переменную

1. Поставьте курсор на переменную.
2. Нажмите:

```text
Space r
```

3. Введите новое имя.
4. Нажмите `Enter`.

## Исправить ошибку через code action

1. Поставьте курсор на строку с диагностикой.
2. Нажмите:

```text
Space a
```

3. Выберите подходящее исправление.

## Быстро отформатировать файл

```text
:format
```

Или назначьте сочетание в `config.toml`:

```toml
[keys.normal]
C-s = ":write"
C-f = ":format"
```

# 15. Минимальный набор, который стоит запомнить

```text
i       вставка перед курсором
a       вставка после курсора
Esc     Normal mode
x       выделить строку
d       удалить
c       заменить
y       копировать
p       вставить
u       отменить
U       повторить отменённое
/       поиск
n       следующее совпадение
gg      начало файла
ge      конец файла
g d     перейти к определению
g r     найти ссылки
Space f открыть файл
Space / поиск по проекту
Space d диагностики
Space k документация
Space r переименование
Space a code action
:w      сохранить
:q      выйти
```

Главный рабочий цикл в Helix обычно выглядит так:

```text
Space f → открыть файл
Space / → найти код в проекте
g d     → перейти к определению
Space k → посмотреть документацию
Space a → применить исправление
Space r → переименовать символ
:format → отформатировать файл
:w      → сохранить изменения
```
