
Если диск уже подключён и смонтирован, сначала найдите его раздел и точку монтирования:

```bash
lsblk -f
```

Посмотрите столбцы `FSTYPE` и `MOUNTPOINTS`. Например, если раздел смонтирован в `/media/имя/Диск`, проверьте права:

```bash
ls -ld "/media/имя/Диск"
```

**Если файловая система ext4**, можно передать владение диском вашему пользователю:

```bash
sudo chown -R "$USER":"$(id -gn)" "/media/имя/Диск"
```

Подставьте фактическую точку монтирования. Это изменит владельца файлов и папок на диске.

**Если диск в NTFS или exFAT**, `chown` обычно не меняет права на сами файлы. Нужно настроить параметры монтирования. Узнайте UUID раздела из `lsblk -f`, затем добавьте в `/etc/fstab` строку, заменив UUID и имя пользователя:

```fstab
UUID=ВАШ-UUID /mnt/внешний-диск ntfs3 defaults,uid=1000,gid=1000,umask=022,nofail 0 0
```

Для exFAT замените `ntfs3` на `exfat`. Чтобы узнать свои UID и GID:

```bash
id
```

Создайте точку монтирования и примените настройки:

```bash
sudo mkdir -p /mnt/внешний-диск
sudo mount -a
```

Если диск нужен только для доступа через графический интерфейс, часто достаточно отключить его и подключить заново после входа в систему. Не запускайте `chmod -R 777` на весь диск: это не исправляет права для NTFS/exFAT и делает файлы доступными всем локальным пользователям.
