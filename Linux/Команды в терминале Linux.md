
### Общие:
- Очистка окна терминала: `Ctrl + L`
- Для fish запустить прошлую команду из под sudo: `Alt + S`
- Для fish и zsh показываем содержимое директории: `Alt + L`
- Для fish и zsh вставляет последний аргумент предыдущей команды: `Alt + .` Можно нажимать несколько раз как с клавишей вверх.


### Перемещение коретки:
- В начало строки: `Ctrl + A`
- В конец строки: `Ctrl + E`
- Назад на слово: `Alt + B`
- Вперед на слово: `Alt + F`

### Удаление:
- Удалить символ слева от коретки: `Ctrl + H`
- Удалить символ справа от коретки: `Ctrl + D`
- Удалить слова слева от коретки: `Ctrl + W`
- Удалить все слева от курсора до начала строки: `Ctrl + U`
- Удалить все справа от курсора до конца строки: `Ctrl + K`
- Вернуть удаленный фрагмент: `Ctrl + Y`

### Поиск:
- Поиск ранее введенных команд: `Ctrl + R`
- Поиск ранее введенных команд: `Ctrl + R`

### Процессы:
- Прервать процесс: `Ctrl + C`
- Приостановить процесс: `Ctrl + Z`
- Список процессов: `jobs`
- Возобновить приостановленный процесс: `fg`
- Возобновить приостановленный процесс в фоне: `bg`

### Фичи

Запустить предыдущую команду:
```bash
!!
```

Если нужно запустить предыдущую команду под sudo:
```bash
sudo !!
```

Последний аргумент предыдущей команды:
```bash
!$
```

Вернуться в предыдущую директорию:
```bash
cd -
```

Создание нескольких директорий через фигурные скобки:
```bash
mkdir -p demo/{src,config,docs}
```

Создание нескольких файлов через фигурные скобки:
```bash
touch app.{html,css,js}
```

Быстрое создание\еопирование бэкапа файла:
```bash
cp config.yml{,.bak}
```
