##### Вывести полный список всех доступных шрифтов

```bash
fc-list
```

##### Только названия шрифтов (без путей к файлам)

```bash
fc-list : family | sort -u
```

#####  Фильтрация и поиск конкретного шрифта

```bash
fc-list : family | grep -i "название_шрифта"
```
  
#####  Поиск шрифтов с поддержкой конкретного языка

```bash
fc-list :lang=ru family | sort -u
```

#####  Вывод только моноширинных шрифтов (для терминала)

```bash
fc-list : spacing=mono family | sort -u
```
