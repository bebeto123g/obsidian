# ⌨️ Полезные сочетания клавиш в Linux терминале

> Эти комбинации работают в большинстве современных оболочек (Bash, Zsh) в режиме Emacs (по умолчанию). Они позволяют редактировать команды и управлять историей, не отрывая рук от клавиатуры.

## 📍 Навигация по строке
| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + A` | Перейти в **начало** строки  |
| `Ctrl + E` | Перейти в **конец** строки  |
| `Alt + B` | Переместить курсор на **слово назад**  |
| `Alt + F` | Переместить курсор на **слово вперёд**  |
| `Ctrl + B` | Переместить курсор на **один символ назад** (аналог стрелки)  |
| `Ctrl + F` | Переместить курсор на **один символ вперёд** (аналог стрелки)  |

## ✂️ Редактирование текста
| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + U` | Удалить всё **от курсора до начала** строки  |
| `Ctrl + K` | Удалить всё **от курсора до конца** строки  |
| `Ctrl + W` | Удалить **слово перед** курсором  |
| `Alt + D` | Удалить **слово после** курсора  |
| `Ctrl + Y` | **Вставить** (yank) последний удалённый текст  |
| `Ctrl + _` | **Отменить** последнее изменение (аналог Undo)  |

## 🕰️ История команд
| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + R` | **Обратный поиск** по истории (начните вводить часть команды)  |
| `Стрелка вверх` / `Ctrl + P` | Показать **предыдущую** команду  |
| `Стрелка вниз` / `Ctrl + N` | Показать **следующую** команду  |
| `!!` | Выполнить **последнюю** команду (часто используется как `sudo !!`)  |
| `!$` | Подставить **последний аргумент** предыдущей команды  |

## 🎛️ Управление процессами и экраном
| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + C` | **Прервать** (убить) текущий процесс  |
| `Ctrl + Z` | **Приостановить** процесс (отправить в фон, вернуть через `fg`)  |
| `Ctrl + L` | **Очистить** экран (аналог `clear`)  |
| `Ctrl + D` | **Выйти** из терминала (EOF) или удалить символ под курсором  |
| `Ctrl + S` | **Заморозить** вывод на экран (полезно при большом потоке логов)  |
| `Ctrl + Q` | **Разморозить** вывод (если нажали `Ctrl + S`)  |

## 🚀 Продвинутые трюки
| Сочетание | Действие |
| :--- | :--- |
| `Tab` | **Автодополнение** команд, путей и файлов  |
| `Ctrl + X, Ctrl + E` | Открыть текущую команду в **текстовом редакторе** (удобно для длинных скриптов)  |

---
*Совет: Если `Alt`-сочетания не работают, проверьте настройки эмулятора терминала (иногда нужно включить «Use Option as Meta key» или аналогичную опцию).*
